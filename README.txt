BRIDGEWORKS CONSULTING SERVICES — STATIC WEBSITE

This package uses only HTML and CSS.

To view:
1. Extract the ZIP.
2. Open index.html in any modern browser.

To publish:
Upload the entire folder to any static web host. Keep the folder structure
unchanged so the shared stylesheet and team photographs continue to work.

Pages:
- index.html
- services.html
- industries.html
- team.html
- about.html
- contact.html

No installation, build command, framework, JavaScript, or server is required.
